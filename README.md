# ⚛️ React Native
Estudos em React Native:

## 🎮 Jogo Pedra, Papel e Tesoura 2.0
Aplicação desenvolvida em **React Native**, recriando o clássico jogo “Pedra, Papel e Tesoura”.
O usuário escolhe sua jogada e enfrenta o computador, com **pontuação automática** para vitórias, derrotas e empates.

## 🚀 Tecnologias Utilizadas
- ⚛️ **React Native**
- 🧩 **Expo**
- 💻 **JavaScript (ES6+)**

## 💡 Conceitos Praticados
- Manipulação de **estado** com React Hooks (`useState`)
- **Renderização condicional** e componentização
- Lógica de **comparação entre jogadas**
- Interface simples, intuitiva.

## 🧠 Aprendizados
Durante o desenvolvimento, foram explorados conceitos fundamentais de React Native, como:
- Estruturação e reutilização de componentes
- Atualização dinâmica da interface
- Interatividade entre usuário e aplicação
